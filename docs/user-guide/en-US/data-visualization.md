# Data Visualization

Charts help you inspect trends and compare values in query results. Start with a query that returns the fields needed for the chart.

## Prepare the data

For a time-series chart, return a timestamp and one or more numeric fields. Limit the time range or aggregate dense data to keep the chart readable.

## Create a chart

1. Run a query and inspect its result table.
2. Open the available chart or visualization action for the result.
3. Select the chart type and the fields used for each axis or series.
4. Preview the chart and adjust its labels and display options.

Line charts are useful for changes over time. Bar charts compare categories. Use a chart type that matches the shape of the returned data.

## Inspect and share

Use chart controls to explore values, change the visible range, or export an image when available. An empty chart may indicate missing numeric fields, an unsuitable timestamp column, or a query that returned no rows.

Return to [Queries](./query-features.md) to refine the data source.
