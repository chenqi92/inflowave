# Installation

Download the package for your operating system and processor from the [InfloWave releases page](https://github.com/chenqi92/inflowave/releases/latest).

## Windows

Run the MSI or EXE installer and follow its steps. Choose x64 for a 64-bit system; the x86 package is available for 32-bit systems. Launch InfloWave from the Start menu after installation.

## macOS

Choose the Apple Silicon package for an M-series Mac, or the Intel package for an Intel Mac. Open the DMG and drag InfloWave into Applications. If macOS asks you to confirm opening a downloaded application, review the publisher and file source before continuing.

## Linux

Choose a DEB package for Debian or Ubuntu, an RPM package for an RPM-based distribution, or the x64 AppImage for a portable application.

For an AppImage, enable its executable permission in your file manager and open it. You can also use a terminal:

```sh
chmod +x InfloWave_*.AppImage
```

Then launch the downloaded AppImage file. If your distribution reports a missing system library, install the required library through its package manager.

Continue with [Quick Start](./quick-start.md).
