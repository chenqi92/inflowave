# Welcome to InfloWave

InfloWave is a desktop workspace for time-series databases. Connect to a server, explore its databases, run queries, and inspect the results in one place.

## Get started

1. Choose **Get Started** below to open the workspace.
2. Add a connection using the **+** button. Select your database type and enter the server address and authentication details.
3. Test the connection before saving it.
4. Select a database, open a query tab, and run a query.

You will need access to a database server. InfloWave connects to your existing data; creating a connection does not create a server.

## Explore the workspace

- **Connections** organize the servers you work with.
- **Database explorer** shows databases, measurements, fields, and tags supported by the selected server.
- **Query tabs** let you write and run queries without leaving the workspace.
- **Results** can be inspected as tables, exported, or visualized.
