# Shortcuts

Keyboard shortcuts and context menus provide quick access to common actions. The shortcuts displayed in the application reflect the current configuration and platform.

## Find and customize shortcuts

Open Settings and select Keyboard Shortcuts to review the available commands. If you customize a shortcut, check for a conflict with another command or an operating-system shortcut.

## Use context menus

Right-click a connection, database, measurement, or result cell to see the actions available for that item. Depending on the item, these may include connecting, refreshing, copying a name, opening a query, or exporting data.

## Work in the editor

The query editor supports familiar editing actions such as undo, redo, find, and completion. Use the Query menu and editor toolbar to locate execution and formatting commands and see their assigned shortcuts.

For operations that change server data, review the active connection and selected database before confirming the action.
